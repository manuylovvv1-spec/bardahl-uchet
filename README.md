# BARDAHL — учёт заказов

## Публикация на GitHub Pages
1. Загрузите все файлы из этой папки в корень репозитория.
2. Главный файл должен называться `index.html`.
3. В Settings → Pages выберите Deploy from a branch, `main`, папку `/(root)`.
4. Откройте опубликованный HTTPS-адрес в Safari на iPhone.

Услуги отображаются без цены в выпадающем списке. Цена подставляется в отдельное поле и может быть изменена перед добавлением в заказ.

Иконка — стилизованная текстовая эмблема BARDAHL, а не официальный исходный файл логотипа компании.
